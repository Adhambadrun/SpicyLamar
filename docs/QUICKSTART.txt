🌶️ SPICY LAMAR
═══════════════════════════════════════

WHAT IT DOES:
Relentlessly watches for the RingCentral Phone window. While it exists,
Spicy Lamar attends to it — focuses the window (restores it if minimized)
and presses the answer shortcut (Alt+F1) roughly every 0.5 s.
Runs as a simple tray icon under its real name: Spicy Lamar.

ALWAYS-ON ATTENTION (default):
  * hunts for the RingCentral Phone window 50x per second
  * focuses + answers it while it exists — never goes quiet
  * F11 pauses/starts the engine at any time

Bounded mode (optional build: -DSPICY_LAMAR_BOUNDED / BOUNDED_MODE=true):
  * fires only on call events (flash / call window / activation)
  * max 3 attempts per ringing episode, 1.5 s apart,
    re-arms after 10 seconds of quiet

INSTALL:
1. Build it with build_portable.bat (C++) or build.bat (C#).
2. Copy "SpicyLamar.exe" anywhere.
3. Double-click to run. No admin rights and no UAC prompt needed.
4. If SmartScreen warns (unsigned exe): More info -> Run anyway,
   or right-click -> Properties -> Unblock.

DASHBOARD:
Right-click tray icon -> "Open Dashboard (F9)".

HOTKEYS:
F9  : Show/Hide Dashboard
F11 : Pause/Start  (also in the tray menu, tooltip, and dashboard status)
F12 : Exit
